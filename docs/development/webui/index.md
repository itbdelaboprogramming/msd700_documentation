# ROS Web UI: Platform

<RoleBadge role="developer" />

The platform side of MSD700: the operator dashboard, the admin console, and the backend/bridge services that connect them to the robot. Organized by the actual screens an operator or admin uses, not by protocol layer. For the robot-side ROS stack these features talk to, see [ROS](/development/ros/); each feature group below links to the ROS Integration page describing that specific wire contract.
