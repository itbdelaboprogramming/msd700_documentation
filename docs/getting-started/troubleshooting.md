# Troubleshooting

<RoleBadge role="user" />

Fixes for common day-to-day issues. This page covers user-level problems only; for hardware/server-level diagnostics, see [Setup &gt; Troubleshooting](/setup/troubleshooting).

| Symptom | Possible cause | What to try |
| --- | --- | --- |
| Can't log in | Wrong credentials, or account not yet created | Double-check your email/password; use Sign up if you have no account; otherwise ask your admin to reset it |
| No units showing on the dashboard | Your account has no unit access yet | Ask your admin to add you to the relevant rental profile |
| A unit shows offline / never connects | The robot itself may be powered off, still booting, or a network issue on-site | Wait a minute for it to finish booting; if it stays offline, escalate to a technician |
| Robot paused itself mid-operation | This is usually the automatic safety pause after a dropped connection, not a fault | Check your own network connection, then resume from the dashboard once reconnected |
| "Robot Stuck" banner won't clear | Usually resolves on its own within a minute; if not, may indicate a real obstruction | Wait briefly; if it persists, escalate to a technician to check the robot in person |
| Live camera feed frozen or won't load | Browser blocked WebRTC, or a temporary network hiccup | Refresh the page; try a different browser (Chrome/Edge recommended); escalate if it keeps happening |
| A saved map, route, or playlist is missing | You may be looking at the wrong unit's Map Database, or the data was removed | Confirm you're on the correct unit; ask a technician if you believe data was lost |
| Someone else has control and I need it | Another operator is actively driving | Use the takeover control in the dashboard, a visible, explicit action, not silent |

## Still stuck?

If the issue looks like a hardware, network, or server problem rather than a usage problem, escalate to a technician via [Setup &gt; Troubleshooting](/setup/troubleshooting).
