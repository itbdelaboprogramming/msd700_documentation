# ナビゲーション

<RoleBadge role="user" />

ナビゲーション画面は、すでに作成済みのマップ上でロボットを操作・移動指示するための画面です。まだマップを作成していない場合は、先に [マッピング](/ja/user-guide/mapping) を行ってください。

## マップを開く

1. メインメニューから **ナビゲーション** を選択します。
2. 一覧から保存済みのマップを選択するか、最後に使用したマップが自動的に読み込まれます。
3. マップが画面に表示され、ロボットの現在位置が色付きの矢印で示されます。

## 手動操作(ジョイスティック / WASD)

自分でロボットを一歩ずつ操作したい場合は手動操作を使用します。

1. **手動操作** ボタンをクリックして有効にします。
2. 画面上のジョイスティック(またはキーボードの **W A S D** キー)で操作します。
   - **W**。前進
   - **S**。後退
   - **A / D**。左折 / 右折
3. 操作を離す(または **停止** をクリック)とロボットは即座に停止します。

::: info 補足
手動操作は常に自動ミッションより優先されます。Autopilot 実行中に手動操作を行うと、Autopilot は一時停止します。
:::

## 地点へロボットを送る(ピンポイント)

1. 手動操作が **オフ** になっていることを確認します。
2. ロボットを行かせたい場所をマップ上でクリックします。
3. その位置にピンが表示されます。**移動** (または確認)をクリックしてロボットを送信します。
4. ロボットは自動的に経路を計画し、途中の障害物を回避します。
5. 進捗は **ステータスバー** で確認できます:「移動中」「到着」、または経路がふさがれている場合は「スタック」。

複数のピンを順番に配置することもでき、ロボットはその順序で巡回します。

## Auto Align(自動位置合わせ)

マップ上でのロボットの位置がわずかにずれている場合(手動で移動させた後など)、その場で回転せずに補正するには **Auto Align** を使用します。

1. ツールバーの **Auto Align** をクリックします。
2. ロボットは周囲のランドマークを使って自身の位置推定を微調整します。
3. 新しい目的地を送る前に、確認メッセージを待ちます。

## Autopilot(無人ミッション)

Autopilot を使うと、ブラウザのタブを閉じてもロボットが事前に計画されたルートやプレイリストを自律的に実行し続けます。

1. 保存済みの [ルートまたはプレイリスト](/ja/user-guide/routes-coverage) を選択します。
2. **Autopilot 開始** をクリックします。
3. ロボットは各ウェイポイントを自動的に処理します。ダッシュボードを閉じても、ミッションはロボット本体で継続されます。
4. 早めに停止したい場合は、ダッシュボードを再度開き **Autopilot 停止** をクリックします。

## 一時停止と再開

- いつでも **一時停止** をクリックすると、その場でロボットが停止します。
- **再開** をクリックすると、中断した箇所から正確に継続します。
- ミッション実行中にブラウザを更新しても、ダッシュボードは自動的に再接続し現在の状態を表示します。進捗が失われることはありません。

## トラブルシューティング

**ロボットが「スタック」と表示される**
: 計画された経路上に何かが障害となっています。ライブカメラで確認し、可能であれば障害物を取り除いてから再開をクリックしてください。

**マップをクリックしても反応がない**
: 手動操作がまだオンになっている可能性があります。オフにするか、正しいロボットに接続されているか(接続インジケーターを確認)を確認してください。

**ロボットが予期せずその場で回転する**
: 安全のため、その場での回転はデフォルトで無効化されています。ロボットがその場での回転を拒否するように見える場合、これは仕様通りの動作です。回転を必要としない経路を探して移動します。

**タブを閉じたら Autopilot ミッションが停止した**
: これは本来起こらないはずです。Autopilot はブラウザではなくロボット側で実行されます。発生した場合は、通信に問題がある可能性があるため管理者に確認してください。
