# ナビゲーション

<RoleBadge role="user" />

ナビゲーション画面は、すでに作成済みのマップ上でロボットを操作・移動指示するための画面です。まだマップを作成していない場合は、先に [マッピング](/ja/user-guide/mapping) を行ってください。

## マップを開く

1. メインメニューから **Navigation** を選択します。
2. 一覧から保存済みのマップを選択するか、最後に使用したマップが自動的に読み込まれます。
3. マップが画面に表示され、ロボットの現在位置が色付きの矢印で示されます。

## 手動操作(ジョイスティック / WASD)

自分でロボットを一歩ずつ操作したい場合は手動操作を使用します。

1. Robot Control パネルの **Manual Override** トグルを ON にします。
2. キーボードの **W A S D** キーで操作します。
   - **W**: 前進(`0.40 m/s`)
   - **S**: 後退
   - **A / D**: 左折 / 右折
   - 精密な操作が必要なときは **Shift** 長押しで低速モード(`0.20 m/s`)
3. すべてのキーから指を離す(または **Stop** をクリック)とロボットは即座に停止します。

::: info 補足
Manual Override は常に自動ミッションより優先されます。2つのトグルは同時にオンにできない排他的な関係にあり、Manual Override を ON にすると自律走行は一時停止します。
:::

## 地点へロボットを送る(ピンポイント)

1. Manual Override が **OFF** になっていることを確認します。
2. ロボットを行かせたい場所をマップ上でクリックします。
3. その位置にピンが表示されます。確認してロボットを送信します。
4. ロボットは自動的に経路を計画し、途中の障害物を回避します。
5. 進捗は **ステータス表示** で確認できます:「On Progress」「Arrived」、または経路がふさがれている場合は「Robot Stuck」。

複数の停止ポイントを順番にキューへ入れ、再利用できるルートとして保存することもできます(詳細は [ルートとカバレッジ](/ja/user-guide/routes-coverage) を参照)。

### マップキャンバスの見方

ロボットが移動している間、キャンバスにはいくつかの指標が重ねて表示されます。

- **青い線**。マップ上で計画された経路です。
- **緑/赤の短い経路**。ロボットが現在実際にたどっている数メートル先までの経路です。
- **赤い点**。ロボットのセンサーが現在検知しているものを示します。
- **ロボット周囲の半透明の輪郭**。安全ゾーンです。ロボットはこの範囲を障害物から空けておきます。

## Auto Align(自動位置合わせ)

マップ上でのロボットの位置がわずかにずれている場合(手動で移動させた後など)、その場で回転せずに補正するには **Auto Align** を使用します。

1. ツールバーの **Auto Align** をクリックします。
2. ロボットはセンサーで見えているものを保存済みのマップと照合して位置を修正します。通常は1秒未満、動かずに完了します。
3. 新しい目的地を送る前に、確認メッセージを待ちます。

## Autopilot(無人ミッション)

Autopilot は、ブラウザのタブを閉じた後も、実行中の無人操作(走行中のルートでも [Operation Playlist](/ja/user-guide/routes-coverage) のスイープでも)をロボット側で継続させます。

1. 操作を開始します。保存済みのルートを読み込んで **Play** をクリックするか、**Operation Playlist** を開いて **Run Playlist** をクリックします。
2. Robot Control パネルの **Autopilot** トグルを ON にします。
3. ロボットは自動的に処理を続けます。ダッシュボードを閉じても、ミッションはロボット本体で継続されます。
4. 早めに停止したい場合は、ダッシュボードを再度開き **Autopilot** トグルを OFF にします(確認を求められます)。

## 一時停止と再開

- いつでも **Pause** をクリックすると、その場でロボットが停止します。
- **Resume** をクリックすると、中断した箇所から正確に継続します。
- ミッション実行中にブラウザを更新しても、ダッシュボードは自動的に再接続し現在の状態を表示します。進捗が失われることはありません。

## トラブルシューティング

**ロボットが「Stuck」と表示される**
: 計画された経路上に何かが障害となっています。ライブカメラで確認し、可能であれば障害物を取り除いてから再開をクリックしてください。

**マップをクリックしても反応がない**
: Manual Override がまだ ON になっている可能性があります。オフにするか、正しいロボットに接続されているか(接続インジケーターを確認)を確認してください。

**ロボットが旋回せずに方向転換の前で一時停止する**
: これは仕様通りの動作です。プランナーはその場で旋回するよりも安全な経路を優先します。進路を見つけるまで少し待ってください。

**タブを閉じたら Autopilot ミッションが停止した**
: これは本来起こらないはずです。Autopilot はブラウザではなくロボット側で実行されます。発生した場合は、通信に問題がある可能性があるため管理者に確認してください。
