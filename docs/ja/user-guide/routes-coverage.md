# ルートとカバレッジ

<RoleBadge role="user" />

マップを用意したら、再利用可能な**ルート**(地点の順序)や**エリア**(掃引するゾーン)を保存し、それらを**プレイリスト**として連結してロボットに自動実行させることができます。

## ルートの保存

1. [ナビゲーション](/ja/user-guide/navigation) 画面で、ロボットに訪問させたい各停止地点をマップ上に順番にピン留めします。
2. **ルートとして保存** をクリックします。
3. ルート名を付けて(例:「朝の巡回」)確定します。

ルートは **ルート** の項目に表示され、毎回すべての地点をクリックし直すことなく、いつでも再利用できます。

## カバレッジエリアの描画

カバレッジエリアは、単一地点への訪問ではなく、通路や開けた部屋全体を体系的に掃引するようロボットに指示するものです。

1. マップツールバーの **エリア描画** をクリックします。
2. 部屋や通路の輪郭に沿って、カバーしたいゾーンの角の点をクリックして配置します。
3. ダブルクリック(または最初の点を再度クリック)して形状を閉じます。
4. そのエリアを **カバー対象**(ロボットが掃引する)にするか、**非カバー/立入禁止**(ロボットが完全に回避する)にするかを選択します。
5. **保存** をクリックし、エリアに名前を付けます。

ロボットは、立入禁止エリアを回避しながらゾーン全体を効率的にカバーする往復(ボウストロフェドン)パターンを計画します。

::: tip 完全なカバレッジのために
デフォルトのレーン間隔(`0.574 m`)は、隣接するパスと約18%重なるように設定されているため、取りこぼす帯がありません。旋回回数を最小限にするには、エリアの長辺が部屋の自然な掃引方向とおおむね一致するように描画してください。
:::

## カバレッジ掃引の実行

1. 一覧から保存済みのエリアを開きます。
2. **カバレッジ開始** をクリックします。
3. ロボットはレーンごとにエリアを掃引します。進捗はパーセンテージ、またはマップ上のハイライト表示として確認できます。
4. 完了するとステータスが **完了** に変わります。

## プレイリストの作成

プレイリストは、複数のルートとカバレッジエリアを1つの無人シーケンスに連結します。

1. **プレイリスト** に移動し、**新規プレイリスト** をクリックします。
2. 実行したい順序でルートやカバレッジエリアを追加します。
3. 必要に応じて、特定のウェイポイントに一時停止(待機時間)を設定します。例えば点検チェックポイントで30秒待機させます。
4. わかりやすい名前を付けてプレイリストを保存します。
5. [ナビゲーション](/ja/user-guide/navigation) からそのプレイリストを選択し、**Autopilot 開始** をクリックすると、シーケンス全体が自動的に実行されます。

## 名前変更または削除

ルート・エリア・プレイリストの名前をダブルクリックすると名前を変更できます(重複する名前は自動的に処理されます)。不要になったものは削除アイコンで削除します。

## トラブルシューティング

**ロボットがエリアの一部を飛ばしてしまう**
: 立入禁止ゾーンがカバレッジエリアと重なっている可能性があります。エリアの形状と、重なっている立入禁止ゾーンを確認してください。

**カバレッジ掃引が早期に停止する / 「完了」と表示されるがエリアが未完了に見える**
: 繰り返し障害物にぶつかった結果、ロボットが諦めた可能性があります。ライブカメラで通路をふさいでいるものがないか確認し、取り除いてからカバレッジを再実行してください。

**プレイリストが次の項目に進まない**
: Autopilot がまだ有効であることを確認してください。手動での一時停止は現在のステップだけでなくプレイリスト全体を一時停止させます。再開をクリックして続行してください。
