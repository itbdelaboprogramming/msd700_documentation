# ルートとカバレッジ

<RoleBadge role="user" />

マップを用意したら、再利用可能な**ルート**(ピンの順序)や**エリア**(掃引するゾーン)を保存できます。保存したエリアは**Operation Playlist**として連結し、まとめて1回で掃引することもできます。

## ルートの保存

1. [ナビゲーション](/ja/user-guide/navigation) 画面で、ロボットに訪問させたい各停止地点をマップ上に順番にピン留めします。
2. **ルート保存** ダイアログを開きます。
3. ルート名を付けて(例:「朝の巡回」)確定します。

ルートは **ルート** の項目に表示され、毎回すべての地点をクリックし直すことなく、いつでも再利用できます。

## カバレッジエリアの描画

カバレッジエリアは、単一地点への訪問ではなく、通路や開けた部屋全体を体系的に掃引するようロボットに指示するものです。

1. マップツールバーでゾーンを描画します。部屋や通路の輪郭に沿って、ゾーンの角の点をクリックして配置します。
2. ダブルクリック(または最初の点を再度クリック)して形状を閉じます。
3. 保存ダイアログでエリアの種類を選択します。**Covered Area**(ロボットが掃引する)か、**Avoided Area**(ガラス間仕切りや段差の周辺など、ロボットが完全に入らないエリア)かを選択します。
4. エリア名を入力して **保存** をクリックします。

ロボットは、Avoided Area を避けながらゾーン全体を効率的にカバーする往復パターンを計画します。

::: tip 完全なカバレッジのために
隣接する掃引パスは重なるようになっているため、取りこぼす帯がありません。旋回回数を最小限にするには、エリアの長辺が部屋の自然な掃引方向とおおむね一致するように描画してください。
:::

## カバレッジ掃引の実行

1. 一覧から保存済みのエリアを開きます。
2. **カバレッジ開始** をクリックします。
3. ロボットはレーンごとにエリアを掃引します。進捗はパーセンテージ、またはマップ上のハイライト表示として確認できます。
4. 完了するとステータスが **完了** に変わります。

## Operation Playlist の作成

Operation Playlist は保存済みの**エリア**を複数まとめて1回で実行します。ルートは含まれず、cover エリアと avoided エリアのみが対象です。

1. ナビゲーションのツールバーで **Operation Playlist** をクリックします。
2. 保存済みのエリアから cover エリアを、掃引したい順序で追加します(ドラッグで並べ替え可能)。avoided エリアも必要に応じて追加します。こちらは順序のある工程ではなく、実行全体にわたる keep-out として扱われます。
3. 名前を入力して **Save New** をクリックします(既存のプレイリストを選んで **Update** することも、鉛筆アイコンで名前を変更することも、**Delete** で削除することもできます)。
4. **Run Playlist** をクリックすると、シーケンス全体が1回のディスパッチで掃引されます。cover エリアが最低1つ必要です。avoided エリアのみのプレイリストはロボットに届く前に拒否されます。
5. ダッシュボードを閉じた後も実行を継続させるには、Robot Control パネルの **Autopilot** を ON にします。

## 名前変更または削除

ルート・エリア・プレイリストの名前をダブルクリックすると名前を変更できます(重複する名前は自動的に処理されます)。不要になったものは削除アイコン(プレイリストの場合は **Delete** ボタン)で削除します。

## トラブルシューティング

**ロボットがエリアの一部を飛ばしてしまう**
: Avoided Area がカバレッジゾーンと重なっている可能性があります。エリアの形状と、重なっている Avoided Area を確認してください。

**カバレッジ掃引が早期に停止する / 「完了」と表示されるがエリアが未完了に見える**
: 繰り返し障害物にぶつかった結果、ロボットが諦めた可能性があります。ライブカメラで通路をふさいでいるものがないか確認し、取り除いてからカバレッジを再実行してください。

**「Save New」/「Run Playlist」がクリックできない**
: プレイリストを保存・実行するには cover エリアが最低1つと名前が必要です。avoided エリアだけでは不十分です。
