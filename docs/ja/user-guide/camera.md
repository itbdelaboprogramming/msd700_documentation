# ライブカメラ

<RoleBadge role="user" />

ライブカメラ画面は、ロボット搭載カメラの映像をリアルタイムでブラウザに直接ストリーミングし、どこにいてもロボットが見ているものを確認できるようにします。

## ライブビューを開く

1. メインメニュー(またはナビゲーション画面)から **カメラアイコン** をクリックします。
2. 数秒以内に映像が読み込まれます。小さなインジケーターで接続品質を確認できます。

## ライブビューの使い方

- **全画面表示**。拡大アイコンをクリックすると、映像を画面いっぱいに表示してより鮮明に確認できます。
- **ピクチャー・イン・ピクチャー**。マップ操作をしながら小さなウィンドウでカメラを開いたままにすることで、監視とナビゲーションを同時に行えます。

## 活用場面

- ナビゲーションやカバレッジ中にロボットが「スタック」と報告した理由の確認
- ミッション開始前に、障害物や人、危険物がないことの確認
- ロボットがいる空間の一般的な遠隔監視

## トラブルシューティング

**映像が読み込まれない / 黒い画面のまま**
: まずインターネット接続を確認してください。問題が続く場合、ロボットがオフラインの可能性があります。ユニット一覧でステータスを確認してください。

**映像がカクつく、またはフリーズする**
: 通常、ブラウザとロボット間のネットワーク帯域幅の問題です。帯域を多く使う他のアプリケーションを閉じるか、管理者に接続状況の確認を依頼してください。

**「name resolution」または接続エラーのメッセージが表示される**
: これはダッシュボードから修正できないネットワーク設定の問題です。管理者または技術者に連絡してください。
