# よくある質問 (FAQ)

<RoleBadge role="user" />

MSD700ロボティクスプラットフォームに関する一般的な運用上の質問への回答です。

---

::: details 1. MSD700ロボットはどのような用途向けに設計されていますか?
MSD700は、倉庫、オフィス廊下、工場などの屋内空間向けの自動運転ロボットです。走行しながらフロアプランを作成し、地点間の移動を自律的にこなし、エリアを体系的にカバーします(清掃や点検など)。
:::

::: details 2. ダッシュボードにログインしましたが、フリート一覧が空です。なぜですか?
ユーザーアカウントは存在しますが、管理者がまだアクティブなロボットを含む**レンタルプロファイル**にそのアカウントを割り当てていません。施設の管理者またはラボの責任者に連絡し、組織のレンタルプロファイルへのアクセス権をアカウントに付与してもらってください。
:::

::: details 3. 2人のオペレーターが同じロボットを同時に操作できますか?
いいえ。安全性を確保するため、各ロボットは1つのアクティブなセッションが保持する**排他的な操作リース**によって管理されています。
- 同僚がロボットを操作中の場合、そのユニットには **In Use** バッジが表示され、コマンドはブロックされます。
- 別のセッションがすでに操作中(2つ目のタブ、別のオペレーター、ユニット本体のローカルダッシュボードなど)の場合、ダッシュボードに **Take over control** 付きのダイアログが表示され、新しいウィンドウへ明示的に制御権を移すことができます。もう一方のセッションは目に見える形で終了します。
:::

::: details 4. ロボットが移動中にノートPCのWi-Fiが切れたり、PCを閉じたりするとどうなりますか?
システムは有効な操作モードに応じて応答します。
- **標準の手動/ナビゲーションモード**: ロボットがブラウザとの接続を**10秒間**失うと、自動的に**セーフティモーションポーズ**を実行して停止しますが、ミッション内容はメモリに保持されます。ブラウザを再接続すると、ミッションは自動的に再開されます。
- **オートパイロットモード ON**: オートパイロットが有効な場合、ロボットはブラウザの切断を無視し、ルートまたはプレイリスト全体を自律的に完了させてからホームベースへ戻ります。
:::

::: details 5. Homebase地点とは何ですか。なぜ重要ですか?
新しいマップ作成時に Play をクリックした時点でロボットがいる場所が、そのマップのホームベース(原点)になります。そのため、あらかじめ充電・ドッキング位置に駐機させてください。今後のプレイリストは、ミッション完了後にロボットを充電ステーションへ自動的に戻すためにこの位置を使用します。設定を忘れた場合は、後から [ナビゲーション](/ja/user-guide/navigation) の **Set Home Base** で修正できます。
:::

::: details 6. ガラス壁、鏡、段差にはどのように対応しますか?
ロボットのセンサーは透明なガラスを透過したり、鏡で混乱したりすることがあるため、ガラス壁がマップに写らないことがあります。ロボットを保護するには、すべてのガラス間仕切りや段差の上に **Avoided Area** を描画してください(詳細は [ルートとカバレッジ](/ja/user-guide/routes-coverage) を参照)。そのゾーンをロボットは立ち入り禁止として扱います。
:::

::: details 7. ロボットの走行速度はどのくらいですか?
**W A S D** キーで操作します。速度は次の2段階に固定されています。
- **通常**: 前進 `0.40 m/s`。
- **低速モード**: **Shift** 長押しで `0.20 m/s` の精密な移動。狭い場所やマッピング時などに使います。
:::

::: details 8. バッテリーはどのくらい持続し、どのように監視されますか?
ロボットは24V LiFePO4大容量バッテリーパックで駆動され、**4〜6時間**の連続自律運用が可能です。
- ユニット操作中、バッテリー状態はダッシュボードのヘッダーにリアルタイムで表示されます。
- バッテリー残量が低下すると、ダッシュボードに警告が表示されます。警告が表示されたらミッションを切り上げ、ロボットをホームベースの充電ステーションへ戻してください。
:::

::: details 9. 建物内にインターネット接続がない場合でもロボットを操作できますか?
はい。すべてのMSD700ロボットは搭載Webサーバーを実行しています。ノートPCをロボットのWi-Fiホットスポット(名前が分からない場合は管理者に確認してください)に直接接続し、ChromeまたはEdgeで `http://<robot-ip>:3000` を開いてください。マッピング、テレオペレーション、カバレッジのすべてのルーチンを完全にオフラインで実行できます。なお、オフライン時もダッシュボードにはデスクトップサイズのブラウザウィンドウが必要です。スマートフォンやタブレットはサポートされていません。
:::

::: details 10. 緊急停止(Emergency Stop)はどのように機能しますか?
赤い **Emergency Stop** ボタンをクリックすると、実行中のすべての自律計画が即座にオーバーライドされ、ロボットが停止して安全状態がラッチされます。その後、ダッシュボードには **Emergency Stop Activated** ページが表示されます。現場の状況を確認し、安全が確保できたらロボットを再起動し、**Go to LOGIN page** ボタンから再度ログインしてください。
:::
