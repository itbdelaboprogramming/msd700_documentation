# アカウントとアクセス

<RoleBadge role="user" />

## ログイン

1. Webブラウザでダッシュボードの URL を開きます(アドレスが分からない場合は管理者に確認してください)。
2. **メールアドレス/ユーザー名** と **パスワード** を入力します。
3. **ログイン** をクリックします。

まだアカウントをお持ちでない場合は、**新規登録** をクリックして情報を入力してください。ロボットが表示されるようになるまでに、フリート管理者による承認やレンタルへの割り当てが必要な場合があります。

## オペレーターと管理者の違い

利用者には2種類の役割があります。

| 役割 | できること |
| --- | --- |
| **オペレーター** | ロボットの操作、マップの作成、ナビゲーションおよびカバレッジミッションの実行、ライブカメラの閲覧。 |
| **管理者** | オペレーターができることに加え、[管理コンソール](/ja/user-guide/admin-console) で他のオペレーター、ロボット、レンタルプロファイルを管理。 |

役割は管理者によって割り当てられるものであり、自分で変更することはできません。

## ユニット(ロボット)の選択

アカウントが複数のロボットにアクセスできる場合、ログイン後に一覧が表示されます。

1. 各ロボットには **名前**、**ステータス**(オンライン / オフライン / 使用中)、バッテリー残量が表示されます。
2. ロボットをクリックして接続します。
3. ロボットが **「使用中」** と表示されている場合、他の誰かが現在操作中です。閲覧は可能ですが、相手が操作を終えるか、明示的に引き継ぎを行うまで操作権を得ることはできません。

## オフラインでの利用(ローカルモード)

インターネット接続のない現場にいる場合でも、クラウドではなくロボットに直接接続することで、ダッシュボードをフル活用できます。

1. ノートPCまたはタブレットを、ロボット搭載のWi-Fiホットスポット(`MSD700_Unit_<ULID>`)に接続します。
2. 通常のクラウドアドレスの代わりに、ブラウザで `http://<jetson-ip>:3000` を開きます。
3. ヘッダーに **ローカルモード** バッジが表示され、ロボットに直接接続していることが確認できます。マッピング、ナビゲーション、カバレッジはすべてオンライン時と同様に動作します。
4. ロボットがインターネット接続のあるWi-Fiに再接続したら、ローカルモードバッジをクリックして **Sync Now** を選択し、オフライン中に記録した内容をクラウドデータベースへ送信します。

## ログアウト

画面上部のアカウント名をクリックし、**ログアウト** を選択します。ロボットが無人ミッション(Autopilot)を実行中の場合、ログアウトしても**ミッションは停止しません**。誤って中断されないよう、そのまま実行が継続されます。

## トラブルシューティング

**ログイン時に「認証情報が無効です」と表示される**
: メールアドレスとパスワードを再確認してください。パスワードを忘れた場合は管理者に連絡してください。

**ログイン後にロボットが1台も表示されない**
: アカウントがまだどのレンタルにも割り当てられていない可能性があります。管理者に追加を依頼してください。

**ロボットが常に「使用中」と表示される**
: 他のオペレーターがセッションを開いたままになっている可能性があります。管理者に確認するか、権限があれば引き継ぎ機能を使用してください。
