# アカウントとアクセス

<RoleBadge role="user" />

## ログイン

1. Webブラウザでダッシュボードの URL を開きます(アドレスが分からない場合は管理者に確認してください)。
2. **ユーザー名** と **パスワード** を入力します。
3. **Proceed** をクリックします。

まだアカウントをお持ちでない場合は、**Sign Up** をクリックしてユーザー名・氏名・メールアドレス・パスワード(確認含め2回)を入力してください。管理者が新しいアカウントをレンタルに割り当てるまで、ロボットは1台も表示されません。

## オペレーターと管理者の違い

利用者には2種類の役割があります。

| 役割 | できること |
| --- | --- |
| **オペレーター** | ロボットの操作、マップの作成、ナビゲーションおよびカバレッジミッションの実行、ライブカメラの閲覧。 |
| **管理者** | オペレーターができることに加え、[管理コンソール](/ja/user-guide/admin-console) で他のオペレーター、ロボット、レンタルプロファイルを管理。 |

役割は管理者によって割り当てられるものであり、自分で変更することはできません。

## ユニット(ロボット)の選択

アカウントが複数のロボットにアクセスできる場合、ログイン後に一覧が表示されます。

1. 各ロボットには **名前**、**ステータス**(Ready / In Use / Pinging / Not Set)、バッテリー残量が表示されます。
2. ロボットをクリックして接続します。
3. ロボットが **「使用中」** と表示されている場合、別のセッションが現在操作中です。開いて見ることはできますが、操作するには明示的に引き継ぐ必要があります。ダイアログ(「This unit is already being operated from …」)で **Take over control**(もう一方のセッションは目に見える形で終了します)か **Leave it running** を選択してください。

## オフラインでの利用(ローカルモード)

インターネット接続のない現場にいる場合でも、クラウドではなくロボットに直接接続することで、ダッシュボードをフル活用できます。

1. ノートPCを、ロボット搭載のWi-Fiホットスポット(名前が分からない場合は管理者に確認してください)に接続します。
2. 通常のクラウドアドレスの代わりに、ChromeまたはEdgeで `http://<robot-ip>:3000` を開きます。マッピング、ナビゲーション、カバレッジはすべてオンライン時と同様に動作します。
3. ロボットがインターネット接続のあるWi-Fiに再接続したら、画面上の **Sync** 機能を使って、オフライン中に記録した内容をクラウドデータベースへ送信します。

## ログアウト

ログアウトしても、実行中の無人ミッション(Autopilot)は**停止しません**。誤って中断されないよう、そのまま実行が継続されます。

## トラブルシューティング

**「The username or password you entered is incorrect」と表示される**
: ユーザー名とパスワードを再確認してください。パスワードを忘れた場合は管理者に連絡してください。(サーバーに接続できない旨のメッセージが表示された場合、入力内容の問題ではありません。ネットワーク接続を確認してください。)

**ログイン後にロボットが1台も表示されない**
: アカウントがまだどのレンタルにも割り当てられていない可能性があります。管理者に追加を依頼してください。

**ロボットが常に「使用中」と表示される**
: 他のオペレーターがセッションを開いたままになっている可能性があります。管理者に確認するか、権限があれば引き継ぎ機能を使用してください。
