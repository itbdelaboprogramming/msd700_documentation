# 管理コンソール

<RoleBadge role="admin" />

管理コンソールは **管理者** 権限を持つアカウントにのみ表示されます。全ユニットのオペレーター、ロボット、レンタルプロファイルを管理するために使用します。

## オペレーター

1. **Admin Console → Operators** に移動します。
2. すべてのオペレーターアカウントを確認し、新規招待や、役割・アクセス可能なレンタルの調整を行えます。
3. アクセスを削除するには、オペレーター名の横にある **Remove** をクリックします。

## ユニット

**Units** タブには **登録済みユニット**(登録済みの全ロボット)と **Pending**(承認待ちの新規ロボット)の2つのビューがあります。

- まったく新しいロボットはまず **Pending** に表示されます。管理者がそこで確認し、**Register**(または **Adopt**)をクリックしてユニットとして登録します。登録するだけでは誰にもアクセス権は与えられません。誰が操作できるかはレンタル割り当てで決まります。
- **登録済みユニット** ビューには、登録済みの全ロボットについて、どのレンタルに貸し出されているか、オペレーター数とマップ数、登録日時、ユニットごとの操作(Rename、Move data、Backup、Swap、Clear data、Unbind、Delete)が表示されます。
- **Unit Status** は、オペレーターのユニットテーブルと同じ方法で数秒ごとにライブで確認されます。**On** にはロボットの状態(**Ready**、オペレーターによる **In use by**、または **Starting up**)と ping 時間(ミリ秒)が表示されます。**Off** は応答がないこと、つまり電源が切れているかインターネットに接続されていないことを意味します。ステータスにポインターを合わせると、バッテリーと稼働時間が表示されます。
- オペレーターはログイン直後の同じユニットテーブルでロボットを確認します。**Ready** の行を選んで **Start** をクリックすると接続します。

## レンタル

**レンタル**は、特定の現場や契約に関連するマップ、ルート、オペレーターをグループ化したものです。

1. **Rentals** に移動し、すべてのアクティブなレンタルプロファイルを確認します。
2. 新しいレンタルプロファイルを作成して新しい現場を設定し、ロボットとオペレーターを割り当てます。
3. レンタルの **バックアップ** 機能を使うと、そのマップとルートすべてをアーカイブできます。大きな変更を行う前や契約終了時に有用です。

## バックアップ

1. **Admin Console → Backups** に移動します。
2. **レンタル** 全体、または単一の **ユニット** データのどちらをバックアップするか選択します。
3. **Create Backup** をクリックします。後で必要に応じて復元できるアーカイブがダウンロードまたは保存されます。
4. 復元するには、バックアップファイルを選択して **Restore** をクリックします。復元はデータを追加する形で行われ、別名で既存するマップを上書きすることはありません。

## システムヘルス

**System Health** はサーバー側が動作しているかを示します。すべての管理者が開くことができ、何も変更しません。

- **Services**: データベース、バックエンド、ロボットのメッセージを運ぶ MQTT ブローカー、ライブリンク(ライブマップとロボット位置)、Web ダッシュボード、メディアサーバー(マップファイル)、カメラシグナリング。それぞれ役割と動作状況を示します。
- **SSL certificates**: Website 証明書(HTTPS)と MQTT ブローカー証明書。残り日数、最終更新日、certbot の次回更新日を表示します。ブローカーの証明書が期限切れになると、Website が動作していてもロボットはブローカーを拒否します。
- **Connections and ports**: サーバーが使う各ポートが応答するか、その速さ。

ステータスは **Working**、**Needs attention**(早めに対応)、**Not working**(オペレーターに影響が出ている可能性)、**Not used** のいずれかです。対応が必要な場合は、その下の短いメモに対処法が書かれています。**Details** にはサーバー管理者に伝える技術的な情報があります。ページは30秒ごとに再確認し、**Check now** ですぐに確認できます。

## 管理者(スーパー管理者のみ)

アカウントにスーパー管理者権限がある場合、**Admins** タブから他のオペレーターを管理者に昇格させたり、その権限を取り消したりできます。

## トラブルシューティング

**管理コンソールが表示されない**
: アカウントが管理者ではなくオペレーターとして設定されています。既存の管理者に役割の変更を依頼してください。

**電源が入っているのにロボットが Off と表示される**
: Off は、ロボットが約12秒間サーバーに応答していないことを意味します。インターネット接続を確認してください。すべてのロボットが Off の場合は **System Health** を開いてください。多くの場合、原因は MQTT ブローカーかその証明書です。

**System Health で MQTT ブローカー証明書が Needs attention になっている**
: Website の証明書は更新されましたが、ブローカーは古い証明書を使っています。表示された日付より前に、サーバー管理者にブローカー証明書の再構築を依頼してください([メンテナンス § 証明書](/ja/setup/maintenance#証明書) 参照)。そうしないとロボットが接続できなくなります。

**ユニット一覧からロボットが消えた**
: 別のレンタルに移動されたか、一時的にオフラインになっている可能性があります。最終確認ステータスを確認してください。

**バックアップを復元しても削除されたロボットのデータが戻らない**
: 元のロボットがすでに存在しない場合、復元処理はデータを別のユニットに再マッピングするよう案内します。画面の指示に従って移行を完了してください。
