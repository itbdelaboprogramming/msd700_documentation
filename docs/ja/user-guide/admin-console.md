# 管理コンソール

<RoleBadge role="admin" />

管理コンソールは **管理者** 権限を持つアカウントにのみ表示されます。フリート全体のオペレーター、ロボット、レンタルプロファイルを管理するために使用します。

## オペレーター

1. **管理コンソール → オペレーター** に移動します。
2. すべてのオペレーターアカウントを確認し、新規招待や、役割・アクセス可能なレンタルの調整を行えます。
3. アクセスを削除するには、オペレーター名の横にある **削除** をクリックします。

## ユニットとフリート

**ユニット** タブには、組織に登録されているすべての物理 MSD700 ロボットが一覧表示されます。

- **ステータス**。オンライン、オフライン、使用中のいずれかがリアルタイムで更新されます。
- **バッテリー**。現在の充電レベル。
- ユニットをクリックすると、現在どのレンタルに属しているかを含む詳細を確認できます。

## レンタル

**レンタル**は、特定の現場や契約に関連するマップ、ルート、オペレーターをグループ化したものです。

1. **レンタル** に移動し、すべてのアクティブなレンタルプロファイルを確認します。
2. **新規レンタル** をクリックして新しい現場を設定し、ロボットとオペレーターを割り当てます。
3. レンタルの **バックアップ** 機能を使うと、そのマップとルートすべてをアーカイブできます。大きな変更を行う前や契約終了時に有用です。

## バックアップ

1. **管理コンソール → バックアップ** に移動します。
2. **レンタル** 全体、または単一の **ユニット** データのどちらをバックアップするか選択します。
3. **バックアップ作成** をクリックします。後で必要に応じて復元できるアーカイブがダウンロードまたは保存されます。
4. 復元するには、バックアップファイルを選択して **復元** をクリックします。復元はデータを追加する形で行われ、別名で既存するマップを上書きすることはありません。

## 管理者(スーパー管理者のみ)

アカウントにスーパー管理者権限がある場合、**管理者** タブから他のオペレーターを管理者に昇格させたり、その権限を取り消したりできます。

## トラブルシューティング

**管理コンソールが表示されない**
: アカウントが管理者ではなくオペレーターとして設定されています。既存の管理者に役割の変更を依頼してください。

**ユニット一覧からロボットが消えた**
: 別のレンタルに移動されたか、一時的にオフラインになっている可能性があります。最終確認ステータスを確認してください。

**バックアップを復元しても削除されたロボットのデータが戻らない**
: 元のロボットがすでに存在しない場合、復元処理はデータを別のユニットに再マッピングするよう案内します。画面の指示に従って移行を完了してください。
