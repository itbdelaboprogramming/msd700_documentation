# マッピング

<RoleBadge role="user" />

ロボットが空間をナビゲートするには、その空間の**マップ**が必要です。マッピングとは、ロボットを走行させることでマップを自動的に構築するプロセスです。

## 新しいマップの開始

1. メインメニューから **マッピング** を選択します。
2. **新規マップ** をクリックし、名前を付けます(例:「倉庫2階」)。
3. **再生** をクリックして記録を開始します。

## マップの構築

マップの構築には2つの方法があります。

- **手動走行**。ジョイスティックまたは **W A S D** キーを使い、隅や行き止まりも含めてエリア全体をゆっくりと走行し、漏れがないようにします。
- **自律探索**。**Auto Explore** をクリックすると、ロボットが自律的にエリアを調査し、行き詰まりを感知すると自動的に後退します。

走行中、マップは画面上でリアルタイムに更新されます。壁や障害物は濃い線として、開けた床面はより明るい色として表示されます。

## 一時停止と確認

- いつでも **一時停止** をクリックして記録を止め、それまでのマップを確認できます。
- **再生** を再度クリックすると、中断した箇所から再開されます。何も失われません。
- ある区域が不完全またはノイズが多いと感じたら、その部分を再走行してください。

## マップの保存

1. エリア全体をカバーしたら、**停止** をクリックします。
2. マップ名を確認し、**保存** をクリックします。
3. 完成したマップは [マップとデータベース](/ja/user-guide/database) に表示され、[ナビゲーション](/ja/user-guide/navigation) で使用できるようになります。

::: warning 記録中にブラウザを閉じないでください
再生中にタブを閉じると、未保存の進捗が失われる可能性があります。必ず先に停止と保存を行ってください。
:::

## 良いマップを作るコツ

- 適度で安定した速度で走行してください。速すぎるとセンサーの読み取りがぶれることがあります。
- 後でナビゲートする予定のあるすべての部屋、通路、出入口をカバーしてください。
- 反射率の高い面やガラス面はできるだけ避けてください。LiDAR センサーを混乱させることがあります。
- 後で部屋の地図がまだらだったり位置がずれていたりする場合、手動で修正するよりその部分を再記録する方が通常は早く済みます。

## トラブルシューティング

**マップが歪んでいる、または壁が揃わない**
: ロボットが速すぎたか、車輪が滑った可能性があります。一時停止して、最後に正常だった区域まで戻り、より慎重に続けてください。

**Auto Explore 中にロボットが動かなくなった**
: エリアの探索が完了したと判断したか、障害物付近で行き詰まっている可能性があります。手動走行に切り替え、見逃した隅を仕上げてください。

**「保存」ボタンがグレーアウトしている**
: 記録が(一時停止ではなく)完全に停止しており、マップに名前が入力されていることを確認してください。
