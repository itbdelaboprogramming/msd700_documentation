# マップとデータベース

<RoleBadge role="user" />

マップデータベースは、保存済みのすべてのマップが保管される場所です。ここからマップを開いたり、名前を変更したり、検索したり、削除したりできます。

## マップの表示

1. メインメニューから **データベース** を選択します。
2. あなた(またはチーム)が保存したすべてのマップが、名前・作成日・サムネイルプレビュー付きのカードまたは行として表示されます。

## マップの検索

上部の**検索ボックス**に入力すると、名前でリストを絞り込めます。複数の拠点やフロアにまたがる多数のマップを管理している場合に便利です。

## マップの名前変更

1. マップ名をダブルクリックします。
2. 新しい名前を入力します。
3. **Enter** キーで確定するか、他の場所をクリックしてキャンセルします。

::: info 補足
マップ名はロボットとレンタルごとにユニークであればよく、別のロボット配下であれば同じ名前を使用できます。
:::

## マップを開く

マップをクリックすると、そのまま [ナビゲーション](/ja/user-guide/navigation) で開きます。前回進行中のミッションがあった場合、ダッシュボードは中断した箇所を正確に復元します。

## マップの削除

1. 削除したいマップの **ゴミ箱/削除アイコン** をクリックします。
2. 確認が求められたら削除を確定します。

::: warning この操作は取り消せません
マップを削除すると、それに紐づくルート、エリア、プレイリストもすべて削除されます。不安な場合は、先にバックアップについて管理者に確認してください([管理コンソール](/ja/user-guide/admin-console) を参照)。
:::

## トラブルシューティング

**表示されるはずのマップが見当たらない**
: そのマップが属するレンタルまたはロボットへのアクセス権がない可能性があります。管理者に確認してください。

**名前変更が失敗する、またはエラーが表示される**
: 同じロボット上に、まったく同じ名前のマップがすでに存在しています。別の名前を選んでください。
