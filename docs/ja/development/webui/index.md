# ROS Web UI: プラットフォーム

<RoleBadge role="developer" />

MSD700のプラットフォーム側: オペレーターダッシュボード、管理コンソール、そしてそれらをロボットに接続するbackend/bridgeサービス。プロトコル層ではなく、オペレーターや管理者が実際に使う画面単位で構成されている。これらの機能が通信するロボット側のROSスタックについては[ROS](/ja/development/ros/)を参照。以下の各機能グループは、その具体的なワイヤー契約を記述したROS連携ページにリンクしている。

::: info このセクションは構築中
このセクションは、以前のプロトコル中心のレイアウトから機能ごとに順次移行されている。まだここに移動していないページは[Start Here > Not Yet Moved](/ja/development/)に引き続き掲載されている。
:::
