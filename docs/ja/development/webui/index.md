# ROS Web UI: プラットフォーム

<RoleBadge role="developer" />

MSD700のプラットフォーム側: オペレーターダッシュボード、管理コンソール、そしてそれらをロボットに接続するbackend/bridgeサービス。プロトコル層ではなく、オペレーターや管理者が実際に使う画面単位で構成されている。これらの機能が通信するロボット側のROSスタックについては[ROS](/ja/development/ros/)を参照。以下の各機能グループは、その具体的なワイヤー契約を記述したROS連携ページにリンクしている。

::: info このセクションは構築中
このセクションは、以前のプロトコル中心のレイアウトから機能ごとに順次移行されている。まだ機能ページに組み込まれていない横断的なリファレンスは、[まずはここから & リファレンス](/ja/development/)に独立したページとして残っている:[REST API リファレンス](/ja/development/api-reference)、[rosbridge プロトコル](/ja/development/rosbridge-protocol)、[Frontend Canvas](/ja/development/frontend-canvas)、[データベース設計](/ja/development/database-schema)、[データ同期](/ja/development/data-sync)、[バックアップ & リストア](/ja/development/backup-and-restore)、[ユニットコンテナライフサイクル](/ja/development/unit-container-lifecycle)。
:::
