# MSD System

The **msd_system** package is the ROS2 workspace for the MSD700 robot development.

**GitHub Repository**: https://github.com/itbdelaboprogramming/msd_system

## Getting Started

You can start by installing the msd_system workspace and running a quick demo to see the robot in action.

1. [Installation](./getting-started/installation)
2. [Quick Demo](./getting-started/quick-demo)

## Environment Setup

For further development and implementation, you need to setup the simulation and hardware environment.

- [Simulation Setup](./setup/simulation): Setup the environment for Gazebo Simulation
- [Real Robot Setup](./setup/real-robot): Setup msd_system to your real robot
