# Konsol Admin

<RoleBadge role="admin" />

Konsol Admin hanya terlihat untuk akun dengan akses **Administrator**. Digunakan untuk mengelola operator, robot, dan profil penyewaan di seluruh armada Anda.

## Operator

1. Buka **Konsol Admin → Operator**.
2. Di sini Anda bisa melihat semua akun operator, mengundang yang baru, dan menyesuaikan peran atau penyewaan mana yang bisa mereka akses.
3. Untuk mencabut akses, klik **Hapus** di samping nama operator.

## Unit & Armada

Tab **Unit** menampilkan semua robot MSD700 fisik yang terdaftar untuk organisasi Anda.

- **Status**: Online, Offline, atau Sedang Digunakan, diperbarui secara real-time.
- **Baterai**: Level daya saat ini.
- Klik sebuah unit untuk melihat detailnya, termasuk penyewaan mana yang saat ini menggunakannya.

## Penyewaan (Rental)

**Penyewaan** mengelompokkan peta, rute, dan operator yang terkait dengan lokasi atau kontrak tertentu.

1. Buka **Penyewaan** untuk melihat semua profil penyewaan aktif.
2. Klik **Penyewaan Baru** untuk membuat lokasi baru, lalu tetapkan robot dan operator ke dalamnya.
3. Gunakan **Backup** pada suatu penyewaan untuk mengarsipkan semua peta dan rutenya: berguna sebelum melakukan perubahan besar atau mengakhiri kontrak.

## Backup

1. Buka **Konsol Admin → Backup**.
2. Pilih untuk mencadangkan seluruh **penyewaan** atau data dari satu **unit** saja.
3. Klik **Buat Backup**: ini akan mengunduh atau menyimpan arsip yang bisa dipulihkan nanti jika diperlukan.
4. Untuk memulihkan, pilih file backup dan klik **Pulihkan**. Pemulihan menambahkan data kembali; tidak akan menimpa peta yang sudah ada dengan nama berbeda.

## Admin (Khusus Superadmin)

Jika akun Anda memiliki hak superadmin, tab **Admin** memungkinkan Anda mempromosikan operator lain menjadi administrator, atau mencabut akses tersebut.

## Pemecahan Masalah

**Saya tidak melihat Konsol Admin**
: Akun Anda ditetapkan sebagai Operator, bukan Administrator. Minta administrator yang ada untuk menaikkan peran Anda.

**Sebuah robot menghilang dari daftar Unit**
: Mungkin telah dipindahkan ke penyewaan lain, atau sedang offline sementara. Periksa status terakhir terlihatnya.

**Memulihkan backup tidak mengembalikan data robot yang sudah dihapus**
: Jika robot asli sudah tidak ada, proses pemulihan akan meminta Anda memetakan ulang data ke unit yang berbeda: ikuti petunjuk di layar untuk menyelesaikan proses pemindahan.
