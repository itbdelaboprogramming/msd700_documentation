# ROS Web UI: Platform

<RoleBadge role="developer" />

Sisi platform dari MSD700: dashboard operator, konsol admin, dan layanan backend/bridge yang menghubungkannya ke robot. Diorganisasi berdasarkan layar aktual yang dipakai operator atau admin, bukan berdasarkan lapisan protokol. Untuk stack ROS sisi robot yang menjadi lawan bicara fitur-fitur ini, lihat [ROS](/id/development/ros/); tiap kelompok fitur di bawah menautkan ke halaman Integrasi ROS yang mendeskripsikan kontrak jalur (wire contract) spesifiknya.

::: info Bagian dalam pengerjaan
Bagian ini sedang dimigrasikan fitur demi fitur dari tata letak lama yang berpusat pada protokol. Referensi mandiri berikut untuk saat ini tetap berada di luar bagian ini: [Referensi REST API](/id/development/api-reference), [Protokol rosbridge](/id/development/rosbridge-protocol), [Frontend Canvas](/id/development/frontend-canvas), [Skema Database](/id/development/database-schema), [Sinkronisasi Data](/id/development/data-sync), [Cadangan & Pemulihan](/id/development/backup-and-restore), dan [Siklus Hidup Kontainer Unit](/id/development/unit-container-lifecycle).
:::
