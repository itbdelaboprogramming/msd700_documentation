# Maps & Database

<RoleBadge role="user" />

The Map Database is where all your saved maps live. From here you can open, rename, search, and delete maps.

## Viewing Your Maps

1. From the main menu, select **Database**.
2. Every map you (or your team) have saved appears as a card or row, with its name, creation date, and a thumbnail preview.

## Searching for a Map

Type into the **search box** at the top to filter the list by name. This is useful once you have many maps saved across different sites or floors.

## Renaming a Map

1. Double-click the map's name.
2. Type the new name.
3. Press **Enter** to confirm, or click elsewhere to cancel.

::: info Note
Map names only need to be unique per robot and rental: the same name can exist under a different robot without conflict.
:::

## Opening a Map

Click a map to open it directly in [Navigation](/user-guide/navigation). If a mission was in progress last time, the dashboard restores exactly where things were left off.

## Deleting a Map

1. Click the **trash/delete icon** on the map you want to remove.
2. Confirm the deletion when prompted.

::: warning This cannot be undone
Deleting a map also removes any routes, areas, or playlists saved against it. If you're not sure, ask your administrator about a backup first: see [Admin Console](/user-guide/admin-console).
:::

## Troubleshooting

**A map I expect to see is missing**
: You may not have access to the rental or robot it belongs to. Check with your administrator.

**Renaming fails or shows an error**
: Another map already uses that exact name on the same robot. Choose a different name.
